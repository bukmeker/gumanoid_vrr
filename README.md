# Unitree G1 EDU — VR Avatar Controller

**Система управления роботом-гуманоидом Unitree G1 EDU в режиме аватара через Meta Quest 2**

## О проекте

Данный проект реализует полноценное **управление роботом Unitree G1 EDU** в режиме аватара с помощью VR-гарнитуры **Meta Quest 2**. 

Оператор в реальном времени контролирует движения головы, корпуса, рук, хват кистями и локомоцию робота с минимальной задержкой (14–18 мс end-to-end).

Проект разработан в рамках дисциплины **«Прикладные интеллектуальные системы»**, кафедра ИИТ, БрГТУ.

### Основные возможности

- Синхронизация головы и поясницы робота с движениями оператора
- Обратная кинематика (IK) для рук
- Управление ходьбой и поворотами через аналоговый стик
- Захват объектов кистями Dex3-1
- Аварийная остановка (кнопка B)
- Watchdog и системы безопасности
- Автоматическая установка зависимостей

## Архитектура системы

```
Meta Quest 2 
    ↓ (WebSocket + Wi-Fi 6)
ПК (Windows + WSL2/Ubuntu) 
    ↓ (CycloneDDS + Ethernet)
Unitree G1 EDU
```

## Быстрый старт

### 1. Установка (выполняется один раз)

```bash
chmod +x setup.sh
./setup.sh
```

### 2. Запуск сервера

```bash
chmod +x run.sh
./run.sh eth0
```

### 3. VR-приложение на Meta Quest 2

1. Откройте проект в **Unity 2022.3 LTS**
2. Укажите IP-адрес вашего ПК в скрипте `VRDataSender.cs`
3. Выполните **Build And Run** (Android)
4. Запустите приложение `G1AvatarVR` на гарнитуре

## Структура проекта

| Файл                        | Назначение                                      |
|----------------------------|-------------------------------------------------|
| `g1_avatar_controller.py`  | Основной сервер, ретаргетинг, управление роботом |
| `VRDataSender.cs`          | Unity-скрипт для Meta Quest 2                   |
| `setup.sh`                 | Автоматическая установка всех зависимостей      |
| `run.sh`                   | Быстрый запуск контроллера                      |

## Управление

| Действие на Quest 2                    | Реакция робота                     |
|---------------------------------------|------------------------------------|
| Поворот/наклон головы                 | Шея + поясница                     |
| Перемещение рук                       | IK-ретаргетинг рук                 |
| Grip (триггер)                        | Сжатие кисти                       |
| Правый аналоговый стик                | Ходьба вперёд/назад + повороты     |
| Кнопка **B** (правый контроллер)      | **Аварийная остановка**            |
